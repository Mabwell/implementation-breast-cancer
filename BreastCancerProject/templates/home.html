Project overview

This project uses the Breast Cancer Wisconsin (Diagnostic) dataset and a Logistic Regression model to provide early prediction and detection assistance. Enter tumor measurements on the Predict page.

  • Model: Logistic Regression (scikit-learn)
  • Database: SQLite (prediction history and users)
  • Frontend: Bootstrap 5, clean medical style
